# ascii_animate

영상을 아스키 아트로 바꿔 소리와 함께 재생합니다. 유튜브 링크나 PC에 있는 영상 파일을 넣을 수 있고, 터미널과 웹 화면 두 가지 방식으로 볼 수 있습니다.

개인 감상용 도구입니다. 내려받은 영상이나 결과물을 다시 배포하지 마세요. 자세한 배경은 [주의 사항](#주의-사항)을 보세요.

## 준비

macOS에서 만들고 확인했습니다. 다음이 필요합니다.

- Python 3.9 이상 (추가 패키지 없음)
- ffmpeg (`ffplay`, `ffprobe` 포함)
- yt-dlp (링크로 재생할 때)

Homebrew로 한 번에 설치합니다.

```
brew install ffmpeg yt-dlp
```

## 터미널에서 재생

```
python3 ascii_play.py "<유튜브 링크 또는 영상 파일 경로>" --size medium
```

Ctrl+C를 누르면 멈추고 터미널이 원래 화면으로 돌아옵니다. 링크로 받은 영상은 `~/.cache/ascii_play/`에 저장되어 같은 링크는 다시 받지 않습니다.

### 화면 크기

글자 수를 정하면, 그 글자 수가 화면에 꽉 차도록 글자 크기가 맞춰집니다. 글자 수가 적을수록 글자가 크고 재생이 부드럽고, 많을수록 세밀하지만 터미널이 느려질 수 있습니다.

| 옵션 | 가로 글자 수 |
|---|---|
| `--size small` | 120 |
| `--size medium` | 200 |
| `--size large` | 300 (최대) |
| `--cols N` | 직접 지정 (300까지) |

`--size`와 `--cols`를 모두 생략하면 현재 터미널 크기를 그대로 씁니다.

기본으로 영상 가장자리를 잘라 터미널을 빈 곳 없이 채웁니다. 원본 비율대로 전체를 보려면 `--no-fill`을 붙이세요.

### 그 밖의 옵션

| 옵션 | 설명 |
|---|---|
| `--mono` | 색 없이 흑백 글자로 표시 |
| `--color-bits 3\|4\|5` | 색의 세밀함. 낮을수록 색은 거칠지만 덜 끊김 (기본 4) |
| `--fps N` | 초당 프레임 수 상한 (기본: 원본, 최대 30) |
| `--invert` | 밝기 반전. 밝은 배경 터미널용 |
| `--no-audio` | 소리 없이 재생 |
| `--audio-offset 초` | 화면을 소리보다 늦춤. 음수면 앞당김 |
| `--stats` | 끝난 뒤 그린 프레임 수, 건너뛴 프레임 수, 출력량 표시 |
| `--no-resize` | VS Code 터미널 글꼴 크기를 자동으로 바꾸지 않음 |
| `--no-gpu` | VS Code 터미널의 GPU 가속을 켜지 않음 |

### VS Code 터미널에서 쓸 때

VS Code 터미널에서 실행하면 재생하는 동안 작업 폴더의 `.vscode/settings.json`을 고쳤다가, 끝나면 원래 내용으로 되돌립니다.

- **글꼴 크기** (`terminal.integrated.fontSize`): `--size`나 `--cols`로 정한 글자 수가 화면에 꽉 차는 크기로 바꿉니다. 재생 중에 패널 크기를 바꾸면 다시 맞춥니다.
- **GPU 가속** (`terminal.integrated.gpuAcceleration`): 꺼져 있으면 켭니다. 꺼진 상태에서는 색이 들어간 글자를 많이 그릴 때 터미널이 크게 느려집니다.

이 동작은 터미널의 현재 위치가 VS Code로 연 폴더 안일 때만 됩니다. 설정 파일에 주석이 들어 있으면 건드리지 않고 그대로 재생합니다.

터미널 패널의 가로세로 비율은 스크립트가 바꿀 수 없습니다. 패널을 최대화하거나 경계선을 끌어 직접 조절하세요.

### 끊길 때

터미널이 글자를 그리는 속도가 한계인 경우가 대부분입니다. 효과가 큰 순서로 시도해 보세요.

1. `--size medium`이나 `--size small`로 글자 수를 줄입니다.
2. `--color-bits 3`으로 색 단계를 줄입니다.
3. `--mono`로 색을 끕니다.
4. 웹 화면으로 봅니다. 구조상 터미널보다 훨씬 가볍습니다.

`--stats`를 붙이면 건너뛴 프레임 수가 나오므로 설정을 바꿔 가며 비교할 수 있습니다.

## 웹 화면에서 재생

```
python3 server.py
```

브라우저에서 http://127.0.0.1:8765 을 열고, 링크를 넣은 뒤 "재생하기"를 누릅니다. "파일 열기"로 PC에 있는 영상을 바로 재생할 수도 있습니다.

- 일시정지, 탐색 막대, 가로 글자 수(60~400), 색상 켜기/끄기를 화면에서 조절합니다.
- 서버는 이 PC에서만 접속되도록 `127.0.0.1`에 열립니다. 포트를 바꾸려면 `PORT=9000 python3 server.py`처럼 실행합니다.
- Chrome 같은 일반 브라우저에서 여는 것을 권합니다. VS Code 내장 브라우저는 AAC 오디오를 재생하지 못해 소리가 나지 않을 수 있습니다. 링크로 받은 영상은 이 경우 서버가 오디오를 Opus로 바꿔 보내지만, "파일 열기"로 연 영상은 그대로라 소리가 빠질 수 있습니다.

## 동작 방식

- **터미널** (`ascii_play.py`): ffmpeg가 영상을 글자 격자 크기로 줄여 프레임을 넘겨주면, 각 칸의 밝기를 글자로, 색을 24비트 색상 코드로 바꿔 출력합니다. 소리는 ffplay가 재생하고, 화면이 밀리면 프레임을 건너뛰어 소리를 따라잡습니다. 출력량을 줄이려고 이전 프레임과 달라진 칸만 다시 보냅니다.
- **웹** (`server.py`, `index.html`): 서버는 영상을 내려받아 브라우저에 넘겨주기만 하고, 아스키 변환은 브라우저가 합니다. 보이지 않는 영상 요소가 소리를 재생하고, 그 프레임을 캔버스에서 읽어 글자로 그립니다.

## 주의 사항

- 유튜브 약관은 영상 다운로드를 금지합니다. 이 도구는 본인 PC에서 혼자 보는 용도로만 쓰세요.
- 이 도구를 인터넷에 공개 서비스로 배포하면 유튜브 약관과 저작권 문제가 생깁니다. 조사 내용은 [reports/유튜브 아스키 영상 서비스 타당성.md](reports/유튜브%20아스키%20영상%20서비스%20타당성.md)에 있습니다. 이 문서는 법률 자문이 아닌 배경 조사입니다.
- 유튜브가 차단 방식을 바꾸면 내려받기가 실패할 수 있습니다. 그럴 때는 `brew upgrade yt-dlp`로 yt-dlp를 최신으로 올려 보세요.
